## 🧩 About

**Neverwinter External Menu** is a curated list of Neverwinter open-source tools:

- **Overlays** — on-screen helpers, layout notes, map tracker, quest tracker
- **Quality-of-Life Helpers** — inventory catalog, loot notes, build planner notes
- **Research Notes** — dungeon routes and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Quest Tracker — follow objectives with an on-screen panel
- Map Notes — annotate zones and points of interest
- Route Notes — record and review dungeon paths
- Playback Notes — review session logs at your own pace

### Wallhack
- Loot Catalog — browse item drops and set categories
- Build Notes — organize class builds and gear sets
- Companion Notes — track companions and mounts

### Aimbot
- Combat Notes — segment study of encounter patterns
- Movement Notes — chain complex maneuvers in open zones
- Session Buffer — save and restore overlay layout
